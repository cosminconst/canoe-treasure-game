# Canoe Treasure Game 🛶🏴‍☠️

A cozy Flappy-Bird-style browser game where a canoe carrying 3 crew members paddles down a river collecting treasure chests and dodging pirate ships.

## Features
- 3 custom crew headshots with pirate hats
- Tap/click to paddle up, drift down with sideways current
- Treasure chests (different sizes) + pirate ships that steal treasure
- Treasure counter with sounds
- Small splash effect under boat (no full-screen flash)
- In-game Store: boat colors, 11 boat types (canoe, kayak, raft, speedboat, dragon boat, Viking longship, submarine, paddle steamer, yacht, sailboat, hovercraft)
- Engine upgrades (+10%/+25%/+45% speed)
- Scenery changes every 90 seconds: dawn/midday/sunset/night with sun/moon/stars, 7 biomes (mangroves, reeds, forest, dunes, jungle, cliffs, lily lagoon)
- Weather effects: rain, mist, falling leaves, snow, sparkles
- Fun facts every 50 score (56 shuffled child-friendly facts) with short fanfare
- Pause/resume, sound toggle, mobile-friendly

## Play
Open `index.html` in a browser or host via GitHub Pages.

## Assets
All game code in `index.html`, images and sounds in `assets/`.
